# Titanic Survival Prediction

A machine learning project to predict passenger survival on the Titanic using a Random Forest Classifier.

## Dataset
Kaggle Titanic Dataset – 891 training samples, 418 test samples

## Approach
- Data cleaning and median imputation for missing values
- Feature encoding (Sex, Embarked)
- Random Forest Classifier (100 estimators)

## Results
- Cross-validation accuracy: 81.15%
- Kaggle public leaderboard score: 0.75358

## Tools
Python, Pandas, NumPy, Scikit-learn
